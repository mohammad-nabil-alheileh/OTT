# AVOD, SVOD, TVOD, FAST

These are the **four main ways an OTT service makes money**. The letters tell you **who pays and how**.

## What the Letters Mean

| Letter(s) | Meaning                            |
| --------- | ---------------------------------- |
| **A**     | Advertising                        |
| **S**     | Subscription                       |
| **T**     | Transactional                      |
| **V**     | Video                              |
| **OD**    | On Demand                          |
| **FAST**  | Free Ad-supported Streaming TV     |

## The Four Models

### AVOD (Advertising VOD)

The viewer **watches for free**, and **advertisers pay**. Ads play before or during the video.

### SVOD (Subscription VOD)

The viewer pays a **fixed monthly or yearly fee** for unlimited access, usually with **no ads**.

### TVOD (Transactional VOD)

The viewer **pays per title**, either to **rent** it for a limited time or to **buy** it.

### FAST (Free Ad-supported Streaming TV)

**Free, ad-supported channels** that run on a **schedule** like traditional TV.

> You tune in and something is already playing.

## Comparison

| Model    | Who pays                  | Viewer sees ads | Viewer picks titles |
| -------- | ------------------------- | --------------- | ------------------- |
| **AVOD** | Advertisers               | Yes             | Yes                 |
| **SVOD** | Viewer (subscription)     | Usually no      | Yes                 |
| **TVOD** | Viewer (per title)        | No              | Yes                 |
| **FAST** | Advertisers               | Yes             | No (channels)       |
