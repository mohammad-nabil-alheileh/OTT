# VOD vs Live

## VOD (Video On Demand)

**VOD** is a **pre-recorded video** sitting in storage. The viewer can **pause, seek, and watch any time**.

## Live

**Live** is video being **captured and streamed as it happens**.

> There is no "whole file" yet, and you can't seek into the future.

## Comparison

| Aspect          | VOD                              | Live                                  |
| --------------- | -------------------------------- | ------------------------------------- |
| **Content**     | Complete file, known duration    | Ongoing, no fixed end                 |
| **Preparation** | Can be processed ahead of time   | Must be processed in real time        |
| **Delay**       | None                             | Usually some seconds behind real life |

## Key Takeaway

- **VOD** = the whole video already exists, so the viewer controls when and where to watch.
- **Live** = the video is still being made, so the viewer follows it as it happens.
